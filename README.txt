FATALLY TERRIBLE LIFESTYLE
Keep Gary alive until his 40th birthday.

WHAT'S IN HERE
  index.html      The whole game. Fonts and graphics are built in, no internet needed.
  manifest.json   Lets phones install it like an app when it's hosted online.
  sw.js           Makes the hosted version work offline after the first visit.
  icon-*.png      App icons.

HOW TO PLAY IT
  On a computer:  Unzip, then double-click index.html. It opens in your browser.

  On a phone:     Phones won't run a game straight from a zip, so host it first:
    itch.io (free, easiest)
      1. Create a project, set "Kind of project" to HTML.
      2. Upload this zip and tick "This file will be played in the browser."
      3. Open the page on your phone. Share > Add to Home Screen.
    GitHub Pages / Netlify Drop also work: upload the unzipped folder.
    Once hosted, "Add to Home Screen" installs it full-screen with Gary as the icon,
    and it keeps working offline.

CONTROLS
  + / -          Route ATP power to an organ (bottom bars)
  Tap a cell     Select it (in the roster or on Gary), then tap an organ to send it
  Pause / 1x     Pause the action or speed it up (spacebar pauses on a keyboard)

DIRECTOR'S CUT (v2)
  Choose between two encounters on most days. Each encounter retains its own choices.
  Tap a threat in the dashboard to inspect its organ or send a selected cell there.
  Surge adds 2 ATP for 8 seconds of running game time; when it expires,
  excess power is removed from lower-priority organs first. Patch repairs one
  bar in the selected damaged organ. Each is usable once per crisis.
  Escape clears selection. Space pauses. Desktop has a side-by-side layout.
